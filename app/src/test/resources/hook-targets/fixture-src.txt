Sources of fixture-035.dex, fixture-039.dex and fixture-041.dex (DexClassNamesTest).

Regenerate (JDK 25, build-tools 37.0.0; put the classes in a jar so d8 sees the non-ASCII names intact):
  javac -encoding UTF-8 --release 11 -d cls fixture/alpha/*.java fixture/beta/*.java
  jar --create --file fixture.jar -C cls .
  java -cp <build-tools>/lib/d8.jar com.android.tools.r8.D8 --min-api 21 --lib <android.jar> --output o35 fixture.jar
  java -cp <build-tools>/lib/d8.jar com.android.tools.r8.D8 --min-api 28 --lib <android.jar> --output o39 fixture.jar
  java -Dcom.android.tools.r8.dexContainerExperiment=true -cp <build-tools>/lib/d8.jar com.android.tools.r8.D8 \
      --min-api 36 --lib <android.jar> --output o41 fixture.jar
  (o35/classes.dex -> fixture-035.dex, o39 -> fixture-039.dex, o41 -> fixture-041.dex, a one-section 041 container)
